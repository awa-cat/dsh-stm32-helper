# 传感器与通信总线（通用）

## 1. 总线怎么选

| 总线 | 适合 | 注意 |
|---|---|---|
| UART | 调试口、点对点模块 | TX/RX 交叉、共地、协议状态机 |
| SPI | 高速、短线、主从 | 无标准应答；线长与地弹 |
| I2C | 多从、低速、板内 | 上拉、地址、挂死恢复 |
| CAN | 多节点、抗扰、较长线 | 终端电阻、波特率、ID 规划 |
| RS485 | 远距离多点 | 半双工方向控制 |
| USB | 高带宽设备 | 枚举与供电 |
| 无线 | 遥控/遥测 | 丢包、延迟、功耗、合规 |

## 2. 传感器分类

| 类别 | 例子 | 软件侧 |
|---|---|---|
| 运动反馈 | 增量/磁/电容编码器 | 定时器捕获或总线读角 |
| 姿态 | IMU（陀螺+加计） | 校准、滤波、融合 |
| 接近/距离 | 红外、ToF、超声 | 盲区、周期、多径 |
| 环境模拟量 | 电位器、电流、光敏 | ADC、标定、滤波 |
| 位置开关 | 限位、光电对射 | 硬件限位优先于软件 |
| 成像 | 摄像头/线阵 | 带宽、曝光、DMA 采集 |

安装比算法更优先：轴向、同心、遮挡、振动、线束应力。

## 3. 可靠 UART 帧（示例）

```c
/* [HEAD0][HEAD1][len][type][payload...][cksum] */
#define HEAD0 0xAA
#define HEAD1 0x55
```

- 校验 sum/CRC；超时进安全态
- 粘包用状态机，不要假设「一次一帧」
- 实时环不靠 `printf` 做业务

## 4. ADC 要点

- 参考电压稳定；高阻源加长采样时间
- 分压/运放调理后做软件标定
- 多通道用扫描/DMA 时确认结果与通道对应关系
- 滤波：滑动平均 / 一阶低通；知悉延迟

```c
float LowPass(float x, float *y, float a)
{
    *y = a * x + (1.0f - a) * (*y);
    return *y;
}
```

## 5. 中断优先级（思路）

| 事件 | 倾向 |
|---|---|
| 控制周期、编码器 | 高 |
| 关键总线接收 | 中高 |
| 日志、菜单 | 低或主循环 |
| SysTick | 需高于会在 ISR 里延时的外部中断 |

DMA：大块发送、摄像头、多路采样，避免堵住控制环。

## 6. I2C 恢复（现场常用）

总线被从机拉住：SCL 打若干时钟脉冲，或对从机断电重启；代码里保留 `I2C_BusRecover()` 可调用。
