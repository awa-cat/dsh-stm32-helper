# 电机、驱动与反馈（通用）

## 1. 按需求选执行器

| 需求 | 常见选择 |
|---|---|
| 连续旋转调速 | 有刷直流 / 无刷 + 驱动或电调 |
| 精确角度/行程 | 伺服、步进、或电机+减速+绝对值编码 |
| 大扭矩低速 | 减速箱有刷/无刷，注意效率与间隙 |
| 短行程推拉 | 气缸+电磁阀，或直线电机/推杆 |
| 轻载快速 | 空心杯等小电机 |

选型顺序：**负载扭矩 → 速度 → 反馈方式 → 驱动与电源**。

## 2. 有刷直流 + H 桥

```
MCU PWM ──► EN/PWM
MCU DIR ──► 方向逻辑
驱动输出 ──► 电机
编码器 A/B ──► MCU 定时器编码器/捕获
```

- 逻辑真值表（IN1/IN2 或 PH/EN）**以模块手册/原理图为准**
- 电流：按连续与堵转选芯片/MOS；注意散热
- 续流：芯片内置或外部二极管/TVS

```c
void Motor_Apply(int16_t duty_signed, uint16_t arr)
{
    if (g_emergency_stop) return;
    /* 限幅 → 方向 GPIO → 写 CCR/PWM */
}
```

## 3. 无刷

| 方案 | 说明 |
|---|---|
| 成品电调 + PWM/模拟油门 | 接线简单，注意油门校准 |
| 现场总线电调（CAN 等） | 多节点机器人常用；协议读厂商文档 |
| 自研 FOC / 六步 | 控制品质高，调试与算力成本高 |

相序错误：抖动、不转或反转。先点动确认方向再闭环。

## 4. 编码器与测速

```c
int32_t d = Encoder_GetDelta(); /* 每周期 */
float rev = (float)d / (float)PPR_EFFECTIVE; /* 含 4 倍频与减速比 */
float v = rev * wheel_or_screw_pitch / dt_s;
```

- 量程与溢出：用 `int32_t`，处理回绕
- 反馈符号与机械方向统一
- 标定：已知位移/转数 vs 积分值

绝对位置：磁编、多圈电池备份编码器、限位+回零。

## 5. 控制层级

```
位置环（外）→ 速度环（中）→ 电流/占空比（底）
```

- 输出限幅：位置限速度，速度限 duty/力矩
- 执行层必须含急停与堵转策略
- 控制周期与定时器配置一致（写进注释）

## 6. 舵机 / 步进（简）

**舵机**：周期与脉宽以手册为准；独立供电、共地；软件限角度防堵转。

**步进**：注意细分数与失步；加减速曲线；力矩随转速下降。

## 7. 机械接口

联轴器对中、防松、线缆随动余量、间隙与润滑、电机与驱动温升。电气软件再好也补不了机械卡死。
