# PCB、线束与抗干扰（通用）

## 1. 电源路径

- 大电流：短、宽、多过孔；避免细线扛电机
- bulk 电容靠近驱动；逻辑 IC 旁路 100 nF
- 功率端子与逻辑分区，丝印标极性与电压
- 线宽初筛可按载流表核算，余量要足

## 2. 信号

- 晶振短走线、包地
- 高速信号参考完整地平面
- 编码器/脉冲线双绞或屏蔽，远离电机线
- 模拟地与数字地策略明确（单点或分区）

## 3. 接插件与线束

| 点 | 做法 |
|---|---|
| 电流 | 端子额定 ≥ 峰值 |
| 防呆 | 电源与信号键位不同 |
| 标签 | 与原理图、代码宏同名 |
| 应力 | 固定点 + 运动段高柔线 |
| 可维护 | 备件与压接工具 |

调试可用杜邦线；长期运行尽量用锁扣端子。

## 4. 结构协同

金属与 PCB 绝缘；电池仓防刺穿；散热通道；测试点（GND/电源/TX/RX/使能）引出。

## 5. EMC 清单

- [ ] 感性负载续流
- [ ] 电源入口滤波
- [ ] 长线差分/屏蔽
- [ ] 无线模块远离电机与开关电源
- [ ] 浪涌/热插拔策略

## 6. 交板 / 交线前检查

- [ ] 原理图与代码引脚表一致
- [ ] 电源树完整（电压/电流/保险）
- [ ] 急停不依赖单一固件路径
- [ ] 连接器与线径匹配
- [ ] 关键网络有测试点
- [ ] 文档：`pinmap`、电源预算、BOM

## 7. 飞线原型

可验证逻辑，不可当稳定交付。进正式样机前制板或加固，并统一地与电源路径。
