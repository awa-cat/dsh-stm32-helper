# 电源、安全与接地（通用）

适用：任意电池供电的嵌入式机电系统。

## 1. 需求先算清

```
能量 Wh ≈ V_nom * Ah
平均电流 I_avg ≈ 各负载占空比加权
峰值 I_peak ≈ 电机堵转 / 多轴同时加速 + 逻辑与算力
压降 ΔV ≈ I * (ESR_battery + R_wire + R_connector)
```

电压跌到欠压阈值 → MCU 复位，是现场最常见故障之一。

## 2. 电源树（推荐模式）

```
电池+ ─ 保险 ─ 开关 ─┬─ 功率母线 → 电机驱动 / 大功率负载
                    └─ DCDC/BEC → 5V / 3.3V → MCU、传感器、通信
电池- ──────── 星形汇点 → 功率地 →（单点）→ 信号地
```

原则：

1. 功率回流不穿过敏感模拟地。
2. 逻辑与功率分线，共地策略明确。
3. 驱动输入 bulk 电容 + 每 IC 100 nF 去耦。
4. 3.3 V 与 5 V 外设注意电平兼容。

## 3. BEC / DCDC 选型

| 项 | 看什么 |
|---|---|
| 输入范围 | 覆盖满电到截止，含尖峰 |
| 输出电流 | ≥ 负载峰值，余量 ≥30% |
| 纹波与噪声 | ADC/视觉敏感时选低噪声 |
| 热 | 压差大时看壳温与散热 |
| 使能 | 可与总开关/安全逻辑联动 |

## 4. 保护与安全

| 措施 | 说明 |
|---|---|
| 主保险 / 自恢复保险 | 短路保护，按母线持续电流选 |
| 分路保护 | 算力、大功率机构独立 |
| 硬件急停 | 切断动力或驱动使能，**不依赖 MCU 存活** |
| 软件急停 | 全局标志：失联、超温、超流、看门狗 |
| 上电默认 | 功率输出关闭，确认后再使能 |

```c
volatile uint8_t g_emergency_stop = 0;

void Motor_Apply(int16_t duty)
{
    if (g_emergency_stop) { /* PWM=0 */ return; }
    /* 限幅后写方向 + 占空比 */
}
```

## 5. 接地与噪声

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 大负载一开就复位 | 压降 / 地弹 | 加粗线、bulk、分路供电 |
| ADC 不稳 | 地参考被功率回流污染 | 星地、模拟地就近、滤波 |
| 通信误码 | 地电位差、边沿 | 共地、短线、必要时差分 |
| 传感器尖峰 | 振动 + 电源噪声 | 减振、LDO、软件滤波 |

## 6. 上电检查单

- [ ] 极性、保险、开关
- [ ] 空载各路电压
- [ ] 急停能切断动力
- [ ] 先逻辑后功率；下载器可连接
- [ ] 单机构点动，再逐个使能
- [ ] 连续运行看温升与电压是否塌

## 7. 锂电安全

不过放、不过充、不短路；鼓包破损停用；充电平衡充并有人值守；接头与线径匹配电流。
