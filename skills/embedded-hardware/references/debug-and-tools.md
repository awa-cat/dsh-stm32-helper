# 调试工具与故障排查（通用）

## 1. 工具

| 工具 | 用途 |
|---|---|
| 万用表 | 通断、电压、二极管 |
| 示波器 | PWM、时钟、总线边沿、电源纹波 |
| 逻辑分析仪 | UART/I2C/SPI 解码 |
| 电流表 | 静态与峰值 |
| 测温 | 驱动与电机 |
| 下载器 | 烧录与 SWD/JTAG 调试 |
| USB 串口 | 日志 |

## 2. 分层排查

```
上电 → 烧录 → 时钟/复位 → 单外设 → 执行器 → 闭环
```

| 故障 | 先查 |
|---|---|
| 完全没电 | 保险、开关、极性、线 |
| 不能下载 | 下载器、供电、BOOT/复位、SWD 线 |
| 复位循环 | 电压跌落、时钟、HardFault |
| 电机不转 | 驱动供电、PWM 有无、使能/方向、堵转 |
| 传感器无效 | 供电地、地址/波特率、最小读写测试 |
| 通信乱码 | 共地、电平、速率、线序 |
| 控制振荡 | 机械间隙、单位错误、DT 与 PID、噪声、电源 |

## 3. 最小测试法（MRTest）

每个外设独立可运行的测试模式，全绿再上闭环：

| 模式 | 通过标准 |
|---|---|
| led | 可见闪烁 |
| uart | 主机收到周期日志/回显 |
| pwm | 示波器或执行器响应占空比 |
| encoder | 方向与计数符合手转 |
| adc | 物理量变化与 raw 合理 |
| imu | 静止接近零漂，转动有符号 |
| can/spi/i2c | 分析仪或回读正确 |

## 4. 日志

实时环外发：时间戳、状态、误差、输出、故障码。故障码枚举化，勿只靠自由文本。

## 5. 报告模板

```
硬件假设：MCU=..., 驱动=..., 总线=..., 规格已确认=是/否
MRTest：通过项 / 未测项
闭环：仅编译 | 已上电点动 | 已闭环（条件）
待确认：电压、减速比、PPR、限位逻辑
```

## 6. 与 DSH 技能

写测试固件用 MCU 相关技能（如 `smartcar-stm32`）；编译烧录串口用 `build-keil` / `flash-keil` / `serial-monitor`；诚实分级用 `stm32-verify-loop`。
